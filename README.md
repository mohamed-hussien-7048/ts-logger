# ☕ T.S Logger System - برومبت ورايقة لربط جهاز البصمة

> **نظام ربط جهاز البصمة (ZKTeco) مع Node.js و SQLite**
> بأسلوب "فتحة خير".. كود متكلف ومظبوط على الفرازة، بياخد الحضور والانصراف من الجهاز لايف ويرميه في الداتابيز بدون لغوصة ولا تكرار!

---

## ☕ الحكاية في كلمتين (Overview)

السيرفر دا معمول مخصوص علشان يتكلم مع أجهزة البصمة من ماركة **ZKTeco**. أول ما الجهاز يلقط بصمة الموظف، السيستم بيسحبها في لحظتها، يقرنها باسم الموظف، ويسجلها في الداتابيز لايف، وفي نفس الوقت بيبعتها للشاشة (Frontend) عن طريق WebSockets بدون ما تحتاج تعمل Refresh.

---

## ⚡ السر في الخلطة (Key Features)

* **ربط مباشر مع الجهاز**: شغال بـ `node-zklib` عشان يكلم أجهزة ZKTeco.
* **تلقيط لايف وحاضر**: أول ما موظف يبصم، البيانات بتسمع في السيرفر في ساعتها.
* **نظام المتابعة الاحتياطي (Polling Fallback)**: لو الجهاز مابيبعتش لايف، السيستم بيبص عليه كل ثانيتين يتأكد إن مفيش بصمة وقعت.
* **داتابيز خفيفة ومحبوكة**: شغال بـ **SQLite** ومعمول لها Unique Constraint عشان مفيش بصمة تتسجل مرتين بالخطأ.
* **تحديث شاشات لايف**: شغال بـ **Socket.IO** يزق البيانات أول بأول للمستعرض.
* **قفل ناعم وسليم (Clean Shutdown)**: لو السيرفر اتأنف أو اتقفل، بيموت كل الـ Connections والـ Database Locks بنظافة.

---

## 🛠️ العدة المستخدمة (Tech Stack)

* **Node.js** (v18+)
* **Express.js** (لعمل الـ REST APIs)
* **Socket.IO** (للتواصل اللحظي مع الـ Client)
* **SQLite** (عن طريق مكتبة `better-sqlite3` السريعة)
* **`node-zklib`** (للاتصال المباشر بجهاز البصمة)

---

## ⚙️ ضبط الأجواء (Environment Variables)

السيستم بيقرأ إعداداته من متغيرات البيئة (Environment Variables)، وتفاصيلها كالتالي:

| المتغير | القيمة الافتراضية | الفائدة |
| :--- | :---: | :--- |
| `PORT` | `5000` | بورت الـ HTTP و Socket.IO |
| `HOST` | `0.0.0.0` | الـ Interface المربوط عليه |
| `DATABASE_PATH` | `data/attendance.db` | مسار ملف قاعدة البيانات SQLite |
| `DEVICE_PORT` | `4370` | بورت جهاز البصمة |
| `DEVICE_CONNECTION_TIMEOUT` | `10000` | مهلة الاتصال بالجهاز (ملي ثانية) |
| `POLLING_INTERVAL` | `2000` | معدل التشيك الدائم (ملي ثانية) |
| `SOCKET_CORS_ORIGIN` | `*` | الدومينات المسموح لها تتكلم مع الـ Socket |
